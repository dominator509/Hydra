# Checklist: Implementation (loop per milestone)
- [ ] Read the docs the milestone lists BEFORE editing; read neighboring code for patterns.
- [ ] Confirm every symbol/route/env/table you're about to use exists (rg/cat) or is created by this milestone.
- [ ] Implement ONE milestone only; smallest reversible choices; copy hard parts from reference/.
- [ ] No scope broadening: not in Files to Change ⇒ don't touch (or Decision Log justification).
- [ ] Run the milestone validation command; confirm the EXACT expected output.
- [ ] Tick Progress; append Decision Log entries (choices, assumptions, deviations).
- [ ] Commit `EP-XXX: M<n> <slug>`.
- [ ] Continue to next milestone unless a STOP condition applies.
